# Emoji artwork

Unmodified Twitter/Twemoji 32px sprite sheet from the repository's installed
`emoji-datasource-twitter` dependency, matching the Tauri EmojiGlyph artwork.
Index generated from the same emoji.json filtering rules as vite.config.ts.
